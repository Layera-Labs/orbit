# Orbit

Embeddable, white-label **design-canvas editor SDK** (image + video) with an agentic layer. Targets React Native (via WebView), Next.js, and React.

- **Roadmap & status:** [ROADMAP.md](ROADMAP.md) — the single source of truth
- **v2 architecture:** [ARCHITECTURE_V2.md](ARCHITECTURE_V2.md)
- **Contributing:** [AGENTS.md](AGENTS.md)
- **Docs:** [docs/](docs/)

## Quick start

```bash
pnpm install
pnpm --filter @orbit/demo dev        # Vite/React demo (v1)
pnpm --filter @orbit/demo-next dev   # Next.js demo (v1)
```
